# 検証の範囲

[validation_report.json](validation_report.json)は、この公開版に対して実行した結果です。元の私的調査の「22件通過」をそのまま流用していません。

通常は`python -m pytest -q`で、同梱転記から人数への変換、主要値、1831年の再交差、原表不一致、欠損、実質指数の既知アンカーと加重平均、助手を含む生産性計算、全列の定義、リンク、図、公開対象・秘密パターンの検査を行います。

Allenの原資料を別途取得して`--allen-pdf`を指定した場合は、原論文の100個のCPIを抽出し、57年すべての実質賃金を再計算して同梱結果と照合します。指定しなければ当該テスト1件はskipになります。この違いを検証記録に残します。

```bash
python scripts/validate.py --allen-pdf _private/allen_2007.pdf
```

自動検査はすべての秘密情報の不在を保証するものではありません。史料の代表性や因果を証明するものでもありません。[公開前確認](../publication_review.md)と組み合わせて使用してください。
